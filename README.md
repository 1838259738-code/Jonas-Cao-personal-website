# Xuanming Cao · Personal Archive

曹轩鸣的个人数字档案，围绕语言、研究、旅行、公开笔记、足球与实践片段展开。

## 本地预览

在项目目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 页面能力

- 中文、英语、德语、荷兰语四语切换，页面标题与描述同步本地化
- 42 个到访国家的交互式世界地图，支持 2023—2026 年筛选
- 本科论文专题与 PDF 阅读入口
- 5 篇小红书笔记的横向截图书架，以及 4 幅生活影像组成的非对称照片墙
- 笔记和生活照片共用无障碍大图浏览器，支持按钮、方向键与 Esc 操作
- 公开笔记、足球、语言、学习与实践的编辑式个人叙事
- 桌面端与移动端响应式布局，兼容减少动态效果偏好

## 文件

- `index.html`：页面内容与结构
- `styles.css`：视觉系统与响应式布局
- `app.js`：多语言、地图、导航和交互
- `assets/hero-blue.jpg`：首页主视觉
- `assets/web/`：为网页加载生成的轻量图片副本；原始素材仍保留在 `assets/`
- `assets/world-land.svg`：世界地图
- `assets/xuanming-thesis.pdf`：论文 PDF
